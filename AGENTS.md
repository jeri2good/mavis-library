# Podcast Lounge project rules

- Scope: this Modal backend worktree on branch `modal` only; do not modify Android, Netlify, the iMac service, or other Mavis services.
- Modal deployment targets only the new `mavis-podcast-studio` app and `podcast-studio` Secret. Never modify pre-existing Modal resources.
- Baseline verified on 2026-10-12: 213 pytest tests pass. Cloud-specific tests must preserve `docs/STUDIO-CONTRACT.md`; GPU/provider generation must run on Modal, never locally.
- Use `.venv/bin/python -m pytest -q` and `.venv/bin/pip check` for verification.
- Validate deployment with `systemd-analyze verify deploy/podcast-lounge.service`.
- Ad-hoc testing binds 127.0.0.1:8141, never the operator's production port 8140.
- Real samples: start the server, run `.venv/bin/python sample_run.py`, inspect `data/sample-results.json`, and independently verify samples with ffprobe. Logs and generated data are ignored by git.
- Never print the token at ~/.secure/podcast-lounge-token, provider keys, Google cookies, or source text. Use fake credentials/clients in unit tests.
- TypeSafe System One only classifies typed questions; it cannot generate dialogue. Legacy local dialogue uses the Hermes gateway. Modal default dialogue uses Qwen3-4B on an L4; only explicitly provisioned `STUDIO_FALLBACK_LLM_*` Secret values enable API fallback. Never route this through a Devin model lane.
- Legacy local mode: one service process/uvicorn worker per data directory, two internal workers. Modal mode: one serialized State actor (`max_containers=1`, `max_inputs=1`) alone opens SQLite on its dedicated Volume; two CPU pipeline containers, one shared L4 GPU container. Close SQLite before Volume commit/reload; audio readers copy to local scratch before streaming. No sudo or outside-service installation by the coding agent.
- Never run overlapping `modal run` instances or rolling deployments against this SQLite actor. Drain generation and state RPCs before deploying; max container caps are per deployed function version, not distributed filesystem locks.
- Modal environment dependencies must always have the same keys locally and remotely; Secrets change the remote environment. Use the fixed-shape `STUDIO_DEPLOY_ENABLED` carrier, never conditionally add an environment Secret based on `STUDIO_ENABLED`.
- Import `AbstractResolver` from `aiohttp.abc` explicitly; relying on a re-export from `aiohttp` failed in a cold Modal container. Chapter benchmarks must use `first_real_chapter`, not the first heading (which can be a contents entry).
- Modal verification environment: install `requirements-modal.txt` in this worktree's `.venv`; run `modal deploy modal_app.py` with ignored `data/` logs, then `.venv/bin/python verify_modal.py --url <captured-url>`. `--resume-topic <id>` resumes a transport-interrupted topic check without duplicating creation. Run GPU experiments via deployed SDK references, not local inference or extra test apps.
- Gateway source of truth: `docs/STUDIO-CONTRACT.md`. Preserve existing statuses and DELETE=204; Gutenberg IDs are JSON strings, signature expiry is Unix seconds, and UID ownership stays out of response payloads.
- Gateway tests inject a fake `STUDIO_SHARED_SECRET` automatically. For workspace-contained scratch data, use `TMPDIR="$PWD/data" .venv/bin/python -m pytest -q --basetemp=data/<unique-run>-tmp`; run long commands in the background with ignored logs under `data/`.
- Never log raw UIDs or signed URL query strings; keep uvicorn access logs/proxy-header trust disabled. Legacy local shared-secret file is `~/.secure/podcast-lounge-shared-secret`; Modal uses `~/.secure/podcast-studio-shared-secret` (32 random bytes as hex), mode 0600, provisioned only outside test runs. Audio CORS is exact-origin opt-in via `STUDIO_AUDIO_ORIGINS`, not a global API grant.

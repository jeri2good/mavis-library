## 6. Podcast gateway (the studio service runs on J's iMac and is NOT on the open internet; this is the public front door). netlify/functions/podcast.mjs, path /api/podcast/<action>
All routes need requireAccess({feature:"podcast"}). Env: STUDIO_URL (https base of the studio, e.g. the Tailscale Funnel path), STUDIO_SHARED_SECRET. If unset -> 503 {code:"studio_not_configured"}.
- POST create {kind,title,text?,url?,gutenbergId?,query?,style,length,language,engine} -> validate exactly like the studio contract (kind book|chapter|article|topic; chapter text <=400k chars; article/book url https only; topic <=300 chars), enforce caps (3/day, max 2 active per user), then POST to {STUDIO_URL}/v1/podcasts with headers X-Studio-Key: <STUDIO_SHARED_SECRET> and X-Mavis-User: <userId or "owner"> and return {id,status}. 10 s upstream timeout, never follow redirects, no cookies.
- GET list, GET job/<id>, DELETE job/<id>: proxy to the studio ONLY for jobs owned by the caller (the studio is told the user id; also keep a Blobs index pod/<userId>/<id> so the gateway can authorise without trusting the studio; owner can see all). 404 not 403 for others' jobs.
- GET audio/<id> -> returns {url, expiresAt}: a short-lived (10 min) URL on the STUDIO host signed with HMAC-SHA256(STUDIO_SHARED_SECRET, `${id}.${exp}.${uid}`) as query params exp&uid&sig, which the studio verifies itself (document the exact format in docs/PODCAST-GATEWAY.md so the studio worker can implement it; export a pure sign/verify function with test vectors). The app downloads/streams audio directly from the studio with that URL (Range works), so the Netlify function never proxies MP3 bytes.
- Response size/time limits, strict JSON, no upstream error text leaked verbatim (map to friendly messages), upstream failures -> 502 {code:"studio_unavailable"}.

## What it is
A small HTTP service on the iMac (port 8140, bind 0.0.0.0 but EVERY route except GET /v1/health requires `Authorization: Bearer <token>`; token auto-generated once into ~/.secure/podcast-lounge-token chmod 600, printed nowhere; constant-time compare; per-IP rate limit). ## API (the app worker codes against exactly this - do not change shapes)
- GET /v1/health (no auth) -> {"ok":true,"engines":{"notebooklm":{"available":bool,"loggedIn":bool,"note":str},"local":{"available":bool,"note":str}}}
- POST /v1/podcasts body {"kind":"book|chapter|article|topic","title":str,"text":str?,"url":str?,"gutenbergId":str?,"query":str?,"style":"deep-dive|brief|debate|critique","length":"short|default|long","language":"en","engine":"auto|notebooklm|local"} -> 202 {"id":str,"status":"queued"}. Validation: kind=chapter needs text (<=400k chars, trim); kind=article needs https url; kind=book needs gutenbergId OR text OR https url; kind=topic needs query (<=300 chars). Reject others 422 with a human message. engine=auto -> notebooklm if loggedIn else local.
- GET /v1/podcasts/{id} -> {"id","status":"queued|sourcing|writing|generating|ready|failed","progress":0-100,"stage":str,"engine":"notebooklm|local","title":str,"kind":str,"style":str,"durationSec":int?,"createdAt":iso,"error":str?,"transcript":str? (local engine only; omit for notebooklm unless the library can fetch it),"sources":[{"title":str,"url":str?}]}
- GET /v1/podcasts -> {"items":[...same minus transcript...]} newest first, max 100.
- GET /v1/podcasts/{id}/audio -> audio/mpeg with HTTP Range support (206), Content-Length, only when ready (409 otherwise).
- DELETE /v1/podcasts/{id} -> 204 (removes files). Retention: auto-delete after 30 days; cap 50 jobs; cap 2 concurrent generations, queue the rest.

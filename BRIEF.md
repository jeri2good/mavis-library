## Goal (J: "WE NEED A WAY TO CREATE PODCAST about any book, chapter, article, website or topic - the book club should have a native podcast lounge")
A native **Podcast Lounge**: pick or paste a subject, choose a style, and a two-host podcast gets produced by the Mavis podcast studio service (NotebookLM-based when available, local TTS engine otherwise) and plays in the app like any audiobook.
## Backend API (studio service; exact shapes)
Base URL = user setting "Podcast studio address" (default empty; show a first-run card explaining it must be the iMac studio, e.g. http://100.98.33.49:8140 over Tailscale; allow http ONLY for 100.64.0.0/10 Tailscale and private LAN hosts the USER typed here - this is the one place cleartext to a private address is allowed; store the Bearer token the user pastes, in EncryptedSharedPreferences/Keystore-backed storage if already used in the app, else DataStore with a clear note; never log it; never send it anywhere but that base URL). All routes except health need `Authorization: Bearer <token>`.
- GET /v1/health -> {ok, engines:{notebooklm:{available,loggedIn,note}, local:{available,note}}}
- POST /v1/podcasts {kind:"book|chapter|article|topic", title, text?, url?, gutenbergId?, query?, style:"deep-dive|brief|debate|critique", length:"short|default|long", language:"en", engine:"auto|notebooklm|local"} -> 202 {id,status}; 422 {detail:str} human message
- GET /v1/podcasts/{id} -> {id,status:"queued|sourcing|writing|generating|ready|failed",progress,stage,engine,title,kind,style,durationSec?,createdAt,error?,transcript?,sources:[{title,url?}]}
- GET /v1/podcasts -> {items:[...]}; GET /v1/podcasts/{id}/audio (audio/mpeg, Range); DELETE /v1/podcasts/{id}.
